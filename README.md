# BVB KOREA (㈜BVB원예자재) 공식 웹사이트

> **"농가의 성공이 곧 우리의 성공입니다."**  
> 120년 전통 네덜란드 BVB Substrates(유럽 RHP 인증)와 스위스 정밀 농업 SWISSGROW 공식 한국 공급원

---

## 📌 주요 특징
- **에디토리얼 럭셔리 디자인**: Oishii & Kinfolk 스타일의 따뜻한 웜 리넨 크림 톤(`bg-stone-50`), 클래식 세리프 폰트(`Noto Serif KR`), 섬세한 1px 헤어라인
- **작물 중심 솔루션**:
  - **딸기 전용 상토**: BC2 (본포용 1등 상토), 코코골드 (정밀 버퍼링 코코피트), BT (육묘용 전용 배지)
  - **스위스그로우 고기능성 영양제**: 딸기 특화 솔루션, 참다래(키위) 수세안정, 사과 착색 및 정품과율 극대화
- **기술 자료실 & 품질 인증**: 수경재배 수분/EC 제어 리포트, 참다래/사과 재배력, 유럽 공인 RHP 무균 보증
- **상담 핫라인**: 직통 전화 `1660-2301` 및 사천 본사/물류센터 안내
